Se guardará y descargará siempre con el nombre:

Brújula, Rutero y Brújula Preventa CD GIRARDOTA-APP.xlsx

Límite: 10 MB. Se verifica la hoja Rutero y se completan automáticamente X a AG antes de guardarlo. No reemplaza un archivo vigente: primero debe eliminarlo un usuario con permiso.

Gestión del archivo diario

El borrado retira el archivo compartido para permitir la carga del día siguiente. Descarga una copia antes de eliminar.

Procesamiento automático X–AG

Al cargar el archivo, se completan automáticamente las columnas X a AG de cada fila con datos de Rutero. Se consultan Monit, Vtts, Consped y BD. La fecha AD se fija al día de procesamiento y AF siempre será AV55. Las claves no encontradas quedan vacías y se informa su cantidad. Para Fecha Preferente Entrega (AB) se busca primero el transporte en Consped A, según la instrucción; si no existe, se usa el Pedido de Rutero S contra Documento de Consped B, una correspondencia comprobable en el ejemplo.

Permisos · Administrador
