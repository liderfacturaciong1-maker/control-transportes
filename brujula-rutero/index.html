Ingreso diario de archivo

Se guardará y descargará siempre con el nombre:

Brújula, Rutero y Brújula Preventa CD GIRARDOTA-APP.xlsx

Capacidad inicial: hasta 100 MB por archivo procesado. Se sube y descarga por bloques; para archivos muy pesados utiliza un computador con suficiente memoria RAM. Se verifica la hoja Rutero y se completan automáticamente X a AG antes de guardarlo. No reemplaza un archivo vigente: primero debe eliminarlo un usuario con permiso.

Gestión del archivo diario

El borrado retira el archivo compartido para permitir la carga del día siguiente. Descarga una copia antes de eliminar.

Procesamiento automático X–AG

Al cargar el archivo, se completan automáticamente las columnas X a AG de cada fila con datos de Rutero. Se consultan Monit, Vtts, Consped y BD. La fecha AD se fija al día de procesamiento y AF siempre será AV55. Las claves no encontradas quedan vacías y se informa su cantidad. Para Fecha Preferente Entrega (AB), se vincula Pedido de Rutero (S) con Documento de Consped (B) y se verifica el cliente Rutero (K) con Cliente Consped (A). Consped no contiene el número de transporte, por lo que se evita una coincidencia incorrecta. Si no existe la referencia, se informa y se deja la celda vacía.

Permisos · Administrador

Asigna permisos independientes para consultar, cargar y eliminar archivos. Los usuarios sin acceso no pueden abrir este submódulo.
