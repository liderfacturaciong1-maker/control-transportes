PILOTO MÓVIL - CONTROL DE TRANSPORTES

La carpeta piloto-movil es independiente y no modifica los archivos existentes.
Para probar en Vercel: suba la carpeta piloto-movil a la raíz del repositorio; después acceda a https://control-transportes-ten.vercel.app/piloto-movil/ (si el proyecto está configurado como sitio estático con esa ruta).
Android: Chrome > Instalar aplicación o Añadir a pantalla de inicio.
iPhone: Safari > Compartir > Añadir a pantalla de inicio.
El piloto no se conecta a Supabase. El simulador de Control Precintos usa almacenamiento local y datos ficticios.
No usar para inventario real. No requiere reemplazar index.html o app.js de producción.
Si la ruta no carga, revise la configuración de Vercel (directorio raíz y reglas de rewrite).
